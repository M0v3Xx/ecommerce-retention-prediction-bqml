## 📌 Project Overview
The goal of this project is to identify customers who are likely to make a repeat purchase (Loyal Customers) versus those who will churn. By accurately predicting customer retention, marketing teams can optimize their budgets by targeting high-risk customers with discounts while avoiding unnecessary ad spend on those already guaranteed to return.

**🔗 [View Interactive Dashboard in Looker Studio](https://datastudio.google.com/s/jf2jdEhHIsc)**

## 🛠️ Tech Stack
* **Data Warehouse Engine:** Google BigQuery
* **Data Engineering & Transformation:** Google Standard SQL
* **Machine Learning:** BigQuery ML (Logistic Regression)
* **Data Visualization & BI:** Looker Studio

## 📂 Dataset
* **Source:** `bigquery-public-data.thelook_ecommerce`
* **Scale:** ~65,000 unique users analyzed.
* **Features Used:** User Demographics (Age, Country, Gender), Traffic Source, and Behavioral Metrics (Total Sessions).

## 🧠 Methodology & Pipeline
The project follows an End-to-End Analytics & Machine Learning pipeline built entirely within the cloud data warehouse:

### 1. Data Engineering & Feature Engineering
* Overcame classical SQL **Fan-out** and **Data Leakage** issues by utilizing Common Table Expressions (CTEs) to pre-aggregate user sessions (`COUNT(DISTINCT session_id)`) before joining with the `orders` and `users` tables.
* Engineered a robust binary target variable (`is_repeat`): `1` for multiple successful orders, `0` for single-order users.

### 2. Machine Learning Training (BQML)
* Trained a **Logistic Regression** model natively in BigQuery using the `CREATE MODEL` statement.
* **Model Performance:** Achieved an **ROC AUC of 0.87**, indicating strong predictive power (significant improvement from the 0.50 baseline).
* Precision: 69.2% | Recall: 49.8% | Accuracy: 78.1%

### 3. Data Transformation for BI (Inference)
* Generated predictions on the entire user base using `ML.PREDICT`.
* Applied the `UNNEST()` function to flatten complex, nested arrays (`RECORD` data type) generated by the model into a strict tabular format (Flat Table). This ensured seamless integration and accurate metric aggregations in Looker Studio.

## 📊 Business Insights & Visualization
The Looker Studio dashboard provides actionable insights for stakeholders:
* **Retention Ratio:** Only 21.6% of the customer base is predicted to naturally return, highlighting a significant churn risk (78.4%).
* **Probability Distribution:** Created custom probability bins (e.g., [0-10%], [10-20%]) using SQL `CASE WHEN` logic to visualize the distribution of customer loyalty. The largest segment (25k+ users) has less than a 10% chance of returning without marketing intervention.
* **Top Retention Clients:** An exportable list of specific `user_id`s sorted by retention probability for direct use in targeted email campaigns.

## 🚀 How to Run the SQL Scripts
1. Open Google Cloud BigQuery Console.
2. Run `01_feature_engineering_and_model.sql` to compile the dataset and train the model.
3. Run `02_inference_and_unnest.sql` to generate predictions and flatten the results for BI export.
